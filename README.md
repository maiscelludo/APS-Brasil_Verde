Sistema web desenvolvido em Java utilizando Spring Boot com o objetivo de auxiliar empresas no registro e acompanhamento de indicadores ambientais relacionados ao Objetivo de Desenvolvimento Sustentável (ODS) 13 – Ação Contra a Mudança Global do Clima.

Tecnologias utilizadas:

Java
Spring Boot
PostgreSQL
HTML
CSS
Bootstrap
Thymeleaf
Funcionalidades:

Cadastro de empresas
Login de usuários
Cadastro de relatórios ambientais
Dashboard para visualização das informações
